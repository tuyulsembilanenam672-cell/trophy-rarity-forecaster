Refresh- and dilution-aware forecaster for GTA VI PlayStation trophies on Exophase: it models player-base growth and per-trophy earner growth in logit space to predict each trophy's earn rate at the target date, with spreads that widen honestly with the horizon.
## Run it
```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
